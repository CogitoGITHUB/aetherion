## `aiu-shell-history info`

This command shows the location of config files on your system

Example output:

```
Config files:
client config: "/Users/ellie/.config/aiu-shell-history/config.toml"
server config: "/Users/ellie/.config/aiu-shell-history/server.toml"
client db path: "/Users/ellie/.local/share/aiu-shell-history/history.db"
key path: "/Users/ellie/.local/share/aiu-shell-history/key"
session path: "/Users/ellie/.local/share/aiu-shell-history/session"

Env Vars:
AIU_SHELL_HISTORY_CONFIG_DIR = "None"

Version info:
version: 18.1.0
```
