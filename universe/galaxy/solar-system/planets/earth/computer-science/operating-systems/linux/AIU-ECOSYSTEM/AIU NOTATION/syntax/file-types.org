* File types
A page may say what kind of page it is with one declaration under the title's start line:

#+BEGIN_EXAMPLE
title start
kind: book
My book
title end
#+END_EXAMPLE

The checker then holds the whole page to that type. A page with no kind: is not checked
against any type.

* What a type decides
Today one thing: which block names the page may use (allowed-blocks). A type may allow
any block (notes) or a fixed list (book).

* Where types live
types/ at the top of the repo holds one module per type, or one folder per type with its
own modules beside type.rkt. filetypes.rkt (in notation system/) finds them by scanning
the folder, so adding a type never edits the engine. See the README, "Making a file type".

* Findings
- unknown-file-type: kind: names a type that has no module
- block-not-in-type: the page uses a block its type does not allow

* Types that exist
- notes: any block
- book: title, section, paragraph, code, comment
